## 1. Quality Gates & Concorrência

1. **Gestão de Concorrência:** `cancel-in-progress: true` para cancelar execuções concorrentes na mesma branch/PR.
2. **Quality Gate:**
   - Setup do runtime Bun v2.
   - Geração de client Prisma (`prisma generate`).
   - Verificação de tipos estritos (`bun run typecheck`).
   - Linter arquitetural estático de conformidade (`bun run check-arch`).
3. **Test Gate:**
   - Push de schema SQLite transacional.
   - Execução do Seed de dados determinístico (`bun run db:seed`).
   - Execução de 100% dos testes unitários e de integração (`bun test --coverage`).
4. **Build & Package Gate:**
   - Construção da imagem Docker multi-stage com cache inteligente (`type=gha`).
