## 🚨 4. Rollback Playbook
- **Rollback Triggers:** Taxa de erro > 0.5% em 5 minutos ou latência p95 > 200ms.
- **Procedimento:** Reverter container para imagem anterior ou tag Git `v0.9.x`. O banco de dados preserva padrão Expand/Contract (não-destrutivo).
